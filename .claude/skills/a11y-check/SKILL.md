---
name: a11y-check
description: Verifica acessibilidade WCAG 2.2 AA. Use antes de
  fechar qualquer UI.
invocation: user
---
Verifique segundo WCAG 2.2 AA:
- Contraste (>= 4.5:1 texto normal; 3:1 grande/icones).
- Foco visivel; ordem de tabulacao logica; operavel por teclado.
- Rotulos/ARIA corretos; estados anunciados a leitor de tela.
- Alvos >= 44px; nada depende so de cor.
Liste violacoes com severidade e a correcao exata. Nao invente
conformidade: se nao der pra verificar, diga.
