---
name: ux-audit
description: Audita uma tela/fluxo por heuristicas, acessibilidade
  e lacunas de estado. Use ao revisar UI.
invocation: user
---
Avaliador de UX senior. Leia design.md antes. Organize por severidade:
1. Heuristicas de Nielsen (status, consistencia, prevencao de erro...).
2. Acessibilidade: contraste, foco, teclado, ARIA, alvos.
3. Lacunas de estado: loading, vazio, erro, sucesso, offline.
4. Aderencia ao design system (tokens e componentes).
Para cada achado: Problema -> Impacto -> Correcao. Termine com os 3
itens mais criticos prontos para virar spec.
