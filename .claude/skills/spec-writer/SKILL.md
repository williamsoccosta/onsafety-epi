---
name: spec-writer
description: Transforma uma ideia em spec executavel antes de
  construir. Use no inicio de toda feature que vai pro ar.
invocation: user
---
A partir da minha ideia, escreva uma spec enxuta (markdown):
- Objetivo (1 frase). Usuario e contexto. Restricoes.
- Criterios de aceite verificaveis (WCAG AA + estados loading/erro/
  vazio/sucesso). Fora de escopo (o que NAO construir).
- Plano em grupos de tarefas pequenos, cada um revisavel.
Pergunte so o essencial; nao invente requisitos. Salve como spec.md.
