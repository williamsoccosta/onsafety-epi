---
name: ds-guard
description: Garante que o codigo use o design system (tokens e
  componentes) em vez de valores soltos.
invocation: auto
---
Antes de escrever/aprovar UI, leia design.md.
- Nunca use cor/espacamento/raio/tamanho solto. Use os tokens.
- Reutilize componentes existentes em vez de recriar.
- Se faltar token/componente, sinalize em vez de improvisar.
Ao revisar, liste cada valor solto e troque pelo token correto.
